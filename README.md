# 🚑 Lifeline.AI – Emergency Transfer Coordination System

Built during the **TrailblazerDX Agentforce Hackathon 2025**, Lifeline.AI is a real-time emergency hospital transfer coordination platform powered by Salesforce, Agentforce, and Lightning Web Components (LWC).

---

## 🌟 Problem Statement

In crisis situations (accidents, collapses, pandemics), lives are lost due to:

- 🚧 Traffic congestion
- 🛏️ Unknown hospital capacity
- 🚑 Ambulance misrouting
- 📝 Manual paperwork and delays

---

## 💡 Our Solution

**Lifeline.AI** coordinates emergency transfers using a team of intelligent micro-agents:

- 🧠 Agentforce AI for hospital selection and triage
- 🚑 Live ambulance tracking
- 🏥 ICU capacity monitoring
- 📋 Auto-generated patient intake forms
- 🤖 Paramedic + hospital dashboards
- 🔔 Slack + Notification alerts

---

## ⚙️ What's Included

This repo contains full metadata for a Salesforce Experience Cloud app:

| Type              | Description                             |
|-------------------|------------------------------------------|
| `Apex Classes`     | Logic for shuttles, patients, routing   |
| `Lightning Web Components (LWC)` | Ambulance UI, Hospital UI    |
| `Flows`           | Patient admission, insurance, logistics |
| `Prompt Templates`| AI agent prompts (Agentforce)           |
| `Permission Sets` | Guest access, admin access              |
| `Profiles`        | Ambulance Driver, Hospital Staff        |
| `Custom Metadata` | Agent registry + config                 |
| `Platform Events` | (Optional) Event-driven automation      |
| `Static Resources`| UI elements like GIFs and images        |
| `Sites`           | Public Experience Builder site          |
